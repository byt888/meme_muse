# Multi-Chain Meme Auto-Trading System

Goal ID: goal_df324e021e06
Goal slug: bsc-meme-auto-trading-system

## 终极目标 (一句话)

构建一套 **多链 Meme 币新闻驱动自动交易系统** (SOL / BSC / ETH 生态 / Robinhood):
同一套策略引擎 + 每条链独立的适配器与阈值,
从名人推文/链上异动中实时捕捉情报, 经精选框架决策后自动执行买卖,
在严格风控下先纸面验证、再小额实盘, 跑通"情报→决策→执行→退出"全链路。

## 多链总体规划 (2026-10-07, 用户拍板)

**设计原则**:
- 策略层 (打分/生命周期/退出/风控) 完全链无关, 只依赖 `ChainAdapter` 接口,
  核心决策链零 LLM, 全部确定性代码。
- 每条链独立三样东西, 不可互抄: ①初筛阈值 ②M50 估值锚 ③纸面门禁样本。
  跨链抄阈值等于用 BSC 的尺子量 SOL 的布, 必错。
- 新链上线三阶段: A=接口验证+适配器 (工程) → B=纸面并行跑+数据定阈值 →
  C=独立纸面门禁 (20 笔/胜率 55%/盈亏比 1.5) → 小额实盘 (需用户逐链授权)。

**各链定位与状态**:

| 链 | 角色 | 数据源 | 状态 |
|---|---|---|---|
| BSC | 首发验证链, 纸面跑通全链路 | GMGN Agent API | ✅ 纸面运行中 (13/20 已平仓, 全硬止损复盘中) |
| SOL | 主力 meme 链, GMGN 基本盘 | GMGN API (SOL 为原生强项, 产品层 SnipeX/跟单均为 SOL only) | 🔨 Phase A 进行中 (适配器+字段对齐) |
| ETH 生态 | 扩展链 | GMGN API (`--chain eth`); 注意主网 gas 贵, 小资金 meme 不经济, 现实落点是 Base 等 L2 | ⏳ SOL 纸面跑出结论后再启动 |
| Robinhood | **不是 meme 链**: 无 trenches、无新币狙击, 只有主流币现货。它在系统里的位置是"大市值现货执行腿" (如未来持有毕业币/主流币), 不进 meme 管线, 不硬套 | Robinhood API (待研究) | ⏳ 远期, 独立策略腿, 另立方案 |

**诚实说明**: Robinhood 没有新币发现机制, meme 筛选管线 (初筛→打分→生命周期)
在它上面无输入可用。把它写进规划是为了执行层完整, 不是为了硬蹭 meme 概念。
ETH 主网同理: gas 成本下 $40 级别账户做 meme 是送钱, 要做也是走 Base。

## 整体架构: 四层情报加工链

任何分支工作都必须能回答: **它服务于哪一层? 与上下游如何协同?**

```
第1层 采集 (眼睛)      J7Tracker 推文流 / GMGN trenches / TG 公告频道
                        ↓ 原始动作 (推文/回复/引用/新币/聪明钱异动)
第2层 提取 (大脑)      把动作翻译成情报: 提到什么项目? 暗示什么? 关联谁?
                        ↓ 结构化情报 (实体, 情绪, 紧迫度)
第3层 映射 (翻译)      情报 → GMGN 关联代币 (同名/同叙事/被站台)
                        ↓ 候选标的 + 安全初筛
第4层 决策执行 (手脚)  精选框架 (动量打分/生命周期/相对估值) → 开仓 →
                      动态止盈/止损 → 退出, 全程风控约束
```

## 四条策略线 (并行, 非互斥; 每条链独立验证)

1. **新闻驱动** (主策略): 名人推文/官方公告 → 情报链 → 交易 (J7 情报库链无关,
   映射层按链查关联代币)
2. **新创建狙击**: trenches 新币 + 初筛 + 精选 (阈值按链独立)
3. **即将打满**: 内盘毕业前埋伏 (SOL= pump.fun 毕业, BSC= fourmeme 毕业)
4. **已开盘**: 即热追踪 + 二段行情 (生命周期状态机驱动, 链无关)

## 关键决策记录 (勿推翻, 除非用户明确)

- **A+B 双轨**: A=GMGN Agent API 主力, B=自持 BSC 钱包备用; D(产品层跟单) BSC 不可用已放弃
- **否决百分比风控**: $40 账户下单笔 2%/5% 会被手续费吃掉, 改用分阶段绝对金额 (待纸面跑验证)
- **并发上限非目标**: 默认空仓, 只因优质标的开仓, 绝不为凑数开仓
- **只有上涨趋势才开新仓** (生命周期状态机铁律)
- **GMGN 每笔 1% 手续费**; Free 套餐限流 5/5, swap 约 0.5 笔/秒
- 预算约 $40 BNB, 钱包与资金**均未到位**, 等用户授权
